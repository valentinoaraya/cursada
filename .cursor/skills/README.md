# Skills de trabajo

Copias adaptadas de [hola-ai](https://github.com/nschurmann/hola-ai) (MIT, Copyright (c) 2026 Nicolas Schurmann). Se invocan a mano. No arrancan solas.

```
/backlog  →  /story  →  /pair
  qué         qué exactamente   cómo
```

| Skill | Hace | No hace |
|---|---|---|
| `/backlog` | Parte una idea en historias verticales de una línea | Inventar requisitos, historias técnicas, estimaciones, issues |
| `/story` | Una historia: 2–3 criterios y un plan corto. Si es grande, con el sí escribe la spec y el seguimiento | Código y tests |
| `/pair` | Un test en rojo, el mínimo para ponerlo verde, y espera | Commit, saltear la spec de un cambio grande, tocar un test para que pase |

Siguen valiendo `AGENTS.md`, `docs/guia-de-trabajo.md` y los ADR ya aceptados. Una skill no reabre una decisión cerrada.
